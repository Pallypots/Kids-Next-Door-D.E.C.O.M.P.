## What a real build does with this

Still nothing reaches it from data: no creator walks the static list of create functions, and no file names actors yet. Called directly, a real build constructs, shuts down and destroys a GmAcObject and a GmAcCharacter completely and answers their small slots. The first time any actor reads its record (slot 2, through `SetupAndConfigure`) with a registry and a record set, it stops with "Gm character: 0x000679E0, the design registry's search by path, is not recovered": the .ADR work recovered loading, not the lookups. Behind that seam, the element access of the value classes (their slot 5) is also not recovered and stops in the ADR code. `test_gmchar` checks that the read stops. With no record (descriptor null) slot 2 of all four classes completes and returns 0.

## Oracle

**What stands in, on both sides alike, and so is not tested:** the registry's search and the values it finds. ## Quirks kept

* FindValueOrDefault measures the whole name only to test it for zero, and passes a second argument nobody reads (TYPE is asked for with 1). FindValue searches the record's parents; the defaults are searched without.
* The actor's NearRange is looked up in its own record only, without the defaults. Words are kept as pointers into the record's values; only Flags and RecyclableWhileActive are copied, the second only when present.
* The node's slot 2 does not test the scene node before writing the collision groups to it; looks up each namespace whether or not its name was found; clears bit 0x100 when bCopyMaterials is absent or false; applies the material assignments once, as the first, whatever was found; always returns 0, so GmAcObject's slot 2, which returns the actor's answer, always returns 0 too.
* AllocateRecords makes none for a VfxWaitingListSize of 0 and three when there is no such word. The actor's shutdown clears as many as the count says, so a count changed after allocating overruns the array.
* GmAcObject's shutdown clears the interaction twice. Its slot 55 is 0 only when the stat sHealth is there and not above zero (NaN counts as not above).
* The character's shutdown runs GmAcObject's first, whether or not initialized, and then its own parts regardless; looks "Shadow" up again and ignores the answer. Slot 21 asks visibility before testing the shadow. Slot 2 does not test the scene actor, the "Shadow" map, or what the create function returns; a joint not found is formatted into a message that is never printed. SetController takes a null owner as the character itself only when m_flags98 has 0x100.
* The list of characters with shadows is packed from the front; add stops at a free slot or the character's own; remove moves everything after it down one and clears the last, even when the tail is all empty.
