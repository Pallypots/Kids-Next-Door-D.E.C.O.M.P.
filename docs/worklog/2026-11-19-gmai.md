## What it is

* **The manager** (no vftable, 0x24 bytes; names inferred). Owner +0x00, DefaultAIAction's name +0x04, actions +0x08 (0x24 bytes each), count +0x0C, the weights of the last pick +0x10, the last action stored +0x14 (eight bytes), the pattern +0x1C (a short name array value), the pattern's index +0x20. Its heap is 0x003B3C88, set by 0x0017CDD0 (called from 0x0012F9CC and 0x0012FA30).
* **An action** (0x24): name, weight (a real; 0 when negative or NaN, -0 kept), modifiers and their count, enabled (1), Repeatable (1 unless the record says otherwise; any boolean value kept, 7 included), NextAction.
* **A modifier** (0x0C): a condition name (the record child's name) and a factor clamped to [0, 1] (NaN and -0 kept). The weight is multiplied by the factor whenever the owner's slot 60 (TestCondition; FaAcNPC's names, include/gm/GmAcNPC.h) answers true.
* **The records**: "AIActions" is a short name array in the NPC's record; each name is a record under the AIActions link whose own value, a real, is the weight; Repeatable (boolean) and NextAction (short name) are children of it; every real child is a modifier (a real "Repeatable" too).
* **Choosing** (0x0017D530): DefaultAIAction first; with a pattern, the pattern's entry and nothing else (an empty pattern leaves DefaultAIAction); else the last action's NextAction; else a weighted random pick over all actions, a second pass allowing repeats when the first totals 0 or less; the random is `(Next() % 10000) * 0.0001f * total` against a running sum kept in the x87 register; nothing picked leaves DefaultAIAction.
* **Storing** (0x0017D340): the last action; with a pattern, its index moves on (wrapping) when the stored name is its current entry, and goes back to 0 when past the end.
* **The chart's commands**: bNPCChooseAIAction 0x0016C0C0 (tells the NPC the choice through slot 49, unless it is the last action and the NPC answers RESUME with non-zero; 1 when there is a choice), vNPCStoreAIAction 0x0016C180 (always 1), bNPCHasAIAction 0x0016C1F0 (whether an enabled action has that name). Each reads the chart's current frame (+0x9C into +0x18) and its character (+0x64).
* **The random generator** (0x00071BB0-0x00071DBA, 0x9C8 bytes): MT19937 with the old 69069 seeding; its holder is the object at 0x002CB0A8 (+0x10), which makes and seeds it with 4357. **I recovered 0x00071D00 and the whole class**: if another agent also recovered 0x00071D00, one of the two should go. Named `AtRandomGenerator` because include/at/AtRandom.h already exists for the particles' table of random words, a different thing.

## Quirks kept

* ReadActions: an empty name is skipped but its slot kept, blank and enabled; the first name that repeats an action already read ends the list there (the same slot and list entry are retried with the count one lower until the loop ends); a name whose record is missing, has no value or not a real stays a blank, enabled slot; the weight is the record's own value; every real child is a modifier, a real "Repeatable" included; a child with no value is a crash.
* The weight test is not a maximum: -0 stays -0, NaN becomes 0. Factors are stored, then clamped in place: NaN and -0 stay.
* Choose: with a pattern, an empty pattern gives DefaultAIAction and stops there. The second pass runs when the total is 0 or less, not when it is NaN.
* Find's second argument is not read (callers pass 0 and 1). SetPattern copies the name to nine bytes, so a longer pattern name is searched by its first eight characters.
* The commands do not test the frame or the class of the character. bNPCChooseAIAction asks RESUME only when the choice repeats the last action.
* The generator's constructor and destructor are one body (index 625, seed 0); unseeded, the first draw twists whatever the words hold. Seed loops on m_index itself.
