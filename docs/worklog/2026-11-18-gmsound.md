# Playing sound notes, voice slots, sound nodes (subsystems `gm/gmsound` and `at/gmsound`), 2026-11-18

For the integrator: this holds what belongs in docs/formats.md, docs/verification.md and docs/STATE.md. State of this work: Semantic-tested. A host MATCH from `tools/verify.py` says nothing about the original compiler.

Two subsystem strings, one oracle: the runner applies a suite's mutants to one source directory, and four of these functions belong to Atlas classes (`src/at/`). `gm/gmsound` is `src/gm/GmSoundPlay.cpp`, `GmSoundNodes.cpp`, `GmRandom.cpp` (suite `gmsound`); `at/gmsound` is `src/at/AtAudioVoices.cpp` (suite `gmsoundat`). Neither string is a prefix of another subsystem.

## What a real build can now do with real `.GON` and `.AOD` data

Read this first. Called directly, a real build now loads a `.GON` file (gon's work), registers it against the lists a real `.AOD` makes (aod's work, which itself stops at the first bank without `DelayLoad`: its `.WBA` load is the XACT seam), finds a note by trigger, and **plays it as far as the emitter**: it stops the Stop note's segment, honours Conditional and Singleton, chooses a segment by weight with the game's own Mersenne twister, and hands it to the note's emitter, to the actor's dynamic sound node (placed at the actor, within range of the listener, through a voice slot), or to a voice slot placed at the actor. There it stops, with a diagnostic: the emitter's slots 15 and 21 to 25 (`AtAudioEmitter::Play` and so on, `src/at/AtAudioDatabase.cpp`) are not recovered, because what they reach is the bank's, and so XACT. A real build therefore makes no sound, and says so at the first play.

Also now real: the `.GOO` sound node reader and its 60 banks (all 16 real files load; GLOBAL.GOO is the pool of 500 dynamic nodes), the `.GOC` and `.GOI` readers (no such file is on the disc), and `RemoveDatabase`. The level manifest's ten `GmAudio*` free functions and `GmAudioFreeDatabase`, which were seams that stopped, now forward to these members (`src/gm/GmLevelManifestHost.cpp`), so a manifest's sound items reach real code. Nothing in the game's own flow reaches `PlayNote` yet: its callers, `GmAcAnimationCallback` slot 4 (0x00160030) and 0x00166FC0, are not recovered, and neither are the manager's constructor (0x0013AB50) and the update that frees `kActor` voice slots.

## The formats

`.GOO`, keywords at 0x002B8FD0: `SoundNodes[n] { Node "name" { ... } ... }` with `Actor "a"` (default: the node's name), `Segment "s"`, `Emitter "e"` (the sound owner's table), `ActorEmitter` (nothing), `VelocityParm`, `AngularVelocityParm`, `CustomParm` (a name and two reals, stored second first), `AnalogInputParm` (three names, two reals), `MaxDistanceFromListener` (its value is never read: it goes by as a token), `PauseWhenAirborne`, `TriggeredOnly`. Real files: 16, 692 nodes; GLOBAL.GOO's 500 `actorNNN` nodes are the pool of dynamic nodes in the first bank. `MinDistanceFromListener` appears in real text and is no keyword: it goes by.

`.GOC`, 0x002B9038: `CollisionSoundNodes[n] { CollisionSoundNode "name" { DedicatedEmitter, DefaultSegment "a" "b" "c", MaterialSegments[n] { "material" "segment" ... }, PlayerInitiatedOnly, RagdollOnly, ImpulseThresholds r r r } }`. `.GOI`, 0x002B9078: `InstanceSoundNodes[n] { InstanceSoundNode "name" { Instances[n] { "name" ... } } }`. Neither on the disc.

The manager (0x003B354C), offsets now known: +0xCE4 ambience, sfx, voice, music, ui emitters; +0xCF8 collsn1-5; +0xD0C forty voice slots {state 0x65 free / 0x66 node / 0x67 actor, emitter actor1-40, actor}; +0xEEC last slot taken; +0x21B0 three impulse thresholds; +0x21BC 60 node banks; +0x248C 10 collision banks; +0x2504 10 instance banks (used flag first). The listener is 0x003B3554; the sound owner's +0x14 is a float scale on a node's range.

Each call runs on both, and after each the worlds are compared, every pointer by the identity of its object. Doubles shared by both sides, logging each call with the identity of its object: emitter slots (Play adds a voice, StopVoice/StopAll mark voices, the loader's Wait removes marked ones), bank lengths and ranges, the actor's slots 22 and 52, a scene node's FinishBody, the matrix table, and the file system.

What a green result does not show, most important first:
* **The emitters are doubles on both sides.** What the emitter's own slots do (making voices, starting them, stopping them through the bank) is not recovered and not compared. The oracle shows the manager reaches them with the same arguments, in the same order, leaving the same state.
* The matrices are doubles: the oracle compares which matrix operations run, on which matrices, with which arguments, not what they compute.
* Distances: the recovered `AtVector3::Distance` returns a float, the original's result may stay in a register. A distance within a rounding of the range could compare differently. No case found one.
* Real `.AOD` lists are not under these cases: the segment lists are written ones.

Not compared: an instance block's text ending inside its braces spins on both sides (only a right curly ends it), so no case does that. Instance and material names after their terminator are uninitialised bytes on both sides; compared up to the terminator. The second array of an instance sound (+0x14) is allocated and never written; not compared.

## Quirks kept

* `PlayNote` adds the next weight before testing the count, so weights that do not reach the pick read one past the last choice and choose it.
* `PlayAtActor` reads App without testing for it; `PlayOnEmitter` plays when there is no App at all.
* `GmActorSoundNodes::Play` takes a position it does not use; `TakeDynamicNode` takes a float it does not use.
* `TakeVoiceSlot` goes round from the slot after the last taken and never looks at the last taken itself. `kActor` slots are never given back by anything here.
* `MaxDistanceFromListener` is never read: the range is the segment's (its bank's slot 12), times the sound owner's scale.
* Out of range, a looping segment waits in the node's `m_segment`; anything else is dropped.
* `RegisterNodes` on null crashes; the manifest's item can pass null for an item that got no bank.
* A `SoundNodes` or `CollisionSoundNodes` block after the first replaces it, leaking it; the Node words themselves are never tested.
* `LoadNodes` resets the tokenizer instead of closing the file.
* `AllocateInstanceBank` with memory refused raises, then hands the bank back unused and uncounted; the load then crashes.
* `FreeCollisionSounds` does not clear the materials pointer after freeing it.
* `GmRandom` never seeds itself: unseeded, the first draw regenerates from whatever the state holds. Its seeding is Knuth's 69069, not the reference `init_genrand`.
