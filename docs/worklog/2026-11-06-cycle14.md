## Mistakes and fixes

* Arenas at different addresses made low pointer bytes differ: now fixed, exactly 16 MB apart.
* On x86 `RtlCaptureContext` captures its caller's frame, so a resume from it leaves the capturing function with callee-saved registers as they stood. `guarded_call` saves them by hand. Three older oracles still use the old pattern: next task.
* A `__fastcall` typedef of 0x00012180 had two stack arguments where the function has `ret 0xC`. The skewed stack showed up as garbage values, clobbered seeds and a false hang, and I first blamed a temporary's lifetime. The third argument is real and unread.
* A patch written through a shell heredoc mangled `\n`. Patches now go through the Write tool.
* 15 mutants survived the first run. Five are equivalent and were dropped with reasons; ten needed states the game does not reach, now set by hand. One I first took for equivalent, the first heap asked twice, is not: a narrower allocation shift makes the wide sum larger than the plain one.
