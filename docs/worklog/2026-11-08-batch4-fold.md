## Oracles

* `add`: the registry double is gone. Libraries load real registries on both sides, each side's own classes; every written .ADR is one short written registry, the parent a written one, and the disc's `LIBRARY.ADD` loads its 11 real .ADR files under the real `GENERIC.ADR`, compared link by link. Freed blocks are not given back while a library runs, on either side (the host's `operator delete` is redirected for that), so the stale registry the owner keeps after a library deletes it names nothing on both sides instead of whatever the host heap reused. The double's knob "registries loaded from birth" has no real counterpart; its case runs on real registries. FindByValue now runs on every boolean and integer column.
* `manifest`: the doubled sound notes item is gone; the real item runs on both sides into a fresh real `GmAudioData` each, loading one written .GON for every path, and the banks are compared after every step. For `SoundNoteDatabases` only, the 127- and 128-character path case is parsed and queued but not run: `AtIoFileRef::OpenWithExtension` (0x000189D0) copies into `char[0x80]`, which such a path and its extension overrun on both sides.
* `adr`: the descriptor's name is compared as its two words.
